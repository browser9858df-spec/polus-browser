## 🚀 My Projects

### 🌐 [Polus Browser](https://github.com/browser9858/polus-browser)
An Among Us themed browser built with Electron, HTML, CSS, and JavaScript. It features:
- 🎵 Among Us sound effects (main menu, crew win, impostor win, Hide n Seek)
- 🟢 Hide n Seek mode (`hns` command)
- 🔴 Impostor mode (`hnsi` command)
- 🎨 Custom themes (dark, light, neon, forest, ocean)
- 💾 LocalStorage (saves theme, search engine, last URL)
- 🍪 Persistent Google login (cookies)
- 🖼️ Custom icon

**Download:** [Polus Browser v1.1.3](https://www.mediafire.com/file/vcy8iztwoj5gvyj/polus-browser_V1.1.3.zip/file)
